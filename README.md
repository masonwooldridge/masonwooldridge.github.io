# Mason Wooldridge — Computer Science Student + Developer Portfolio

A cinematic, responsive portfolio that presents my education, professional software experience at Valvoline, AI research, and personal projects.

## What it demonstrates

- Real-time Three.js planet rendering with directional lighting and custom atmosphere shaders
- Procedural Saturn rings and a canvas-based animated starfield
- Responsive layouts designed for desktop and mobile
- Motion that respects `prefers-reduced-motion`
- Accessible navigation, labels, forms, and external-link behavior
- Project and experience summaries optimized for quick recruiter scanning

## Technical stack

- HTML5
- CSS3
- JavaScript
- Three.js / WebGL
- Anime.js

## Run locally

No build step is required. Start any static file server from the project root, for example:

```bash
python3 -m http.server 4180
```

Then open `http://127.0.0.1:4180`.
